# Security policy

This repository contains documentation only. Vulnerabilities in OpenAjo itself
belong in the repository that holds the affected code:

| Affected component | Report privately at |
| --- | --- |
| `circle` / `reputation` contracts | [openajo-contract → Report a vulnerability](https://github.com/OGRoute/openajo-contract/security/advisories/new) |
| SDK, indexer, web app | [openajo-app → Report a vulnerability](https://github.com/OGRoute/openajo-app/security/advisories/new) |

Do not open a public issue for a vulnerability.

Report a documentation problem here if it could lead someone to lose funds —
for example, a guide that describes slashing or payout rules incorrectly. Use
[this repository's private reporting form](https://github.com/OGRoute/openajo-docs/security/advisories/new)
if you would rather not describe it in public.

OpenAjo is **unaudited and deployed to Stellar testnet only**. Do not use it
with mainnet funds.
